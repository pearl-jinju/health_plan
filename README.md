# 헬스 에이전트

갤럭시 Chrome의 전경 탭에서 사용하는 한국어 운동 코치 MVP다. 기본 화면에서 가슴만을 선택하면 벤치프레스 40kg × 10회 × 3세트가 준비된다. 루틴의 다른 종목은 체크하여 같은 세션에 포함할 수 있다.

## 실행

```powershell
python build.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:8765/`를 연다. Python 표준 라이브러리로 정적 산출물을 생성한다. Node.js가 설치된 환경에서는 `node --test src/core.test.mjs`로 상태 및 계산 테스트를 실행한다.

## 운동과 기록

운동 시작을 누르면 한국어 안내를 시작한다. 준비·카운트·휴식·실제 기록 확인은 이어폰의 다음 곡, 선택적으로 켜는 음성 명령, 화면 버튼에서 같은 상태 전환을 사용한다. 음성 안내는 기기의 한국어 합성 음성을 사용한다. 실제 기기별 전달 정확도는 테스트리스트에서 확인한다.

운동과 기록 수정은 IndexedDB에 저장한다. 브라우저의 사이트 데이터를 지우면 기록이 삭제될 수 있다. 브라우저 프로필과 사이트 주소마다 저장 공간이 다르다.

## Render

`render.yaml`은 `python3 build.py`로 빌드해 `dist`를 제공하는 정적 사이트 설정이다. Render가 접근할 GitHub 원격 저장소에 소스를 올린 뒤 배포할 수 있다. 운동 데이터는 기기 브라우저에 저장한다.
