# 헬스 에이전트

갤럭시 Chrome의 전경 탭에서 사용하는 한국어 운동 코치 MVP다. 기본 화면에서 가슴만을 선택하면 벤치프레스 40kg × 10회 × 3세트가 준비된다. 루틴의 다른 종목은 체크하여 같은 세션에 포함할 수 있다.

## 실행

```powershell
python build.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:8765/`를 연다. Python 표준 라이브러리로 정적 산출물을 생성한다. Node.js가 설치된 환경에서는 `node --test src/core.test.mjs src/audio.test.mjs src/adfit.test.mjs`로 진행 상태, 계산, 템포, 오디오 및 광고 표시 검사를 실행한다.

## 운동과 기록

‘운동 준비’를 누르면 오디오를 활성화하고 첫 세트를 대기 상태로 둔다. 이어폰의 ‘다음 곡’으로 세트를 시작한다. 휴식 타이머가 끝나면 다음 시작 신호를 기다린다. 더 쉬고 싶으면 운동 화면에서 ‘휴식 +30초’를 누른다. 화면 버튼과 선택 음성 명령으로도 진행할 수 있다. 음성 안내는 기기의 한국어 합성 음성을 사용한다. 실제 기기별 전달 정확도는 테스트리스트에서 확인한다.

‘휴식’의 ‘이어폰 버튼 확인’에서는 이어폰이 보낸 ‘다음 곡’과 ‘재생·일시정지’를 구분해 표시한다. 운동 준비 화면에는 Chrome 미디어 재생 상태가 표시된다. 처음 연결할 때 짧은 알림음이 한 번 나며, ‘이어폰 다시 연결’에서 미디어 재생을 다시 요청할 수 있다.

‘목표’, ‘템포’, ‘음성’, ‘휴식’ 탭을 눌러 설정을 바꾼다. 무게와 횟수 카드를 왼쪽으로 밀면 다음 값으로 올라가고 오른쪽으로 밀면 이전 값으로 내려간다. 벤치프레스 중량은 한 칸에 2.5kg이다.

종목 목표 아래의 템포에서 동작과 멈춤 구간을 각각 설정한다. 벤치프레스 기본값은 내리기 3초, 아래에서 멈춤 1초, 밀기 1초, 위에서 멈춤 없음이다. 구간이 시작될 때 신호음이 나며, ‘신호음 듣기’에서 먼저 확인할 수 있다. 변경한 템포는 브라우저에 종목별로 저장된다.

‘음성’에서 카운트 목소리를 선택하고 ‘미리 듣기’를 누르면 ‘하나, 둘, 셋, 넷’을 들을 수 있다. 기본 ‘남성 트레이너 (AI 음성)’는 1~20회에 포함된 음원을 사용한다. 21회 이상이거나 음원이 아직 준비 중이면 기기의 한국어 음성으로 이어진다. 한국어 기본 음성이나 기기가 제공하는 특정 음성을 선택할 수도 있다. 선택한 목소리는 브라우저에 저장되며, 운동을 준비할 때 해당 세션에 적용된다.

남성 트레이너 음원은 [Supertone Supertonic 3](https://huggingface.co/supertone-oss-archive/supertonic-3/tree/aafc6e32416a594460b32413efc49d7fe4ce6d46)의 M1 한국어 합성 음성으로 생성했다. 1~20의 개별 MP3와 4회 카운트 미리듣기를 포함한다.

운동과 기록 수정은 현재 사이트 주소와 브라우저 프로필의 IndexedDB에 저장한다. 다른 기기나 프로필에 기록을 동기화하는 서버는 없다. 같은 기기와 프로필을 함께 이용하면 같은 기록을 볼 수 있다. 사이트 데이터를 지우면 기록이 삭제될 수 있다.

## 카카오 애드핏

공개 Render 주소에서 운동을 완료한 뒤 요약 화면 아래에 공간이 충분하면 300×250 배너를 한 번 불러온다. 광고는 카카오의 Web SDK로 삽입한다. 앱이 광고 단위에 제공하는 값은 광고 설정 정보다. 설정의 ‘완료 화면 광고 표시’를 끄면 해당 브라우저에서 광고 스크립트를 로드하지 않는다. 실제 광고 송출은 카카오 매체 심사와 광고 응답에 따른다. [애드핏 SDK 가이드](https://adfit.github.io/wiki/web-guide/)

## Render

`render.yaml`은 `python3 build.py`로 빌드해 `dist`를 제공하는 정적 사이트 설정이다. 배포 주소는 [헬스 에이전트](https://health-agent-8y4x.onrender.com/)다. 운동 데이터는 기기 브라우저에 저장한다.
